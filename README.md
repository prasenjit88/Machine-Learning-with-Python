# Machine Learning with Python 🧠🐍

This repository contains a collection of applied machine learning projects implemented using Python. Each project tackles a real-world problem using supervised learning algorithms and includes model building, evaluation, and documentation.

## 📂 Contents

### 1. 📄 [Gmail Spam Detection Using Logistic Regression](./Gmail%20Spam%20Detection%20Using%20Logistic%20Regression.pdf)
- **Goal:** Classify emails as spam or not using logistic regression.
- **Techniques:** Text preprocessing (TF-IDF), binary classification, model evaluation.
- **Metrics:** Accuracy, Precision, Recall, F1-Score.

### 2. 📄 [Lead Scoring Case Study Using ML](./Lead%20Scoring%20case%20study%20using%20ML.pdf)
- **Goal:** Predict which leads are most likely to convert into customers.
- **Techniques:** Logistic Regression, Feature Engineering, Business Insights.
- **Outcome:** Helps marketing teams focus efforts on high-converting leads.

### 3. 📄 [Predict Diabetes with Machine Learning](./Predict%20Diabetes%20with%20Machine%20Learning.pdf)
- **Goal:** Predict the likelihood of diabetes based on patient data.
- **Dataset:** PIMA Indian Diabetes dataset.
- **Techniques:** Decision Trees, KNN, and Logistic Regression with evaluation metrics.

### 4. 📄 [21A91A0588 Internship Certificate](./21A91A0588%20internship%20certificate.pdf)
- **Details:** Official certificate of internship participation and completion.
